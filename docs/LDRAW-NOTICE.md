# LDraw library snapshot

This project redistributes an **unmodified** copy of the LDraw.org Parts Library
as a GitHub Release asset, outside the source-code history.

- Project snapshot date: 2026-11-01. This date identifies our snapshot, not an
  upstream LDraw release number.
- Upstream version: Parts Update 2026-10 (2026-10-26).
- Upstream: https://library.ldraw.org/library/updates/complete.zip
- Library website: https://library.ldraw.org/
- Project asset: `ldraw-complete-2026-11-01.zip`
- SHA-256: `023083918da2d3697c794fb4267975509584f3611b993095874206a803fa610f`
- Archive size: 146,853,687 bytes.

The LDraw.org part authors are credited in each part's original `Author` and
`!HISTORY` headers. The license applicable to each part is specified by its
original `!LICENSE` header; this snapshot includes CC BY 4.0, CC BY 2.0 / 4.0,
and legacy CCAL 2.0 notices. The library data are **not** relicensed under this
application's software license.

The archive retains its original `CAreadme.txt`, `CAlicense.txt`,
`CAlicense4.txt`, and `Readme.txt`, together with all original part attribution
and license headers. The installer preserves these files. See:

- https://creativecommons.org/licenses/by/2.0/
- https://creativecommons.org/licenses/by/4.0/

The original archive also includes the `mklist` auxiliary program by Lars C.
Hassing and its source archives (`mklist-c.zip`, `mklist1_4.zip`, and
`mklist1_6.zip`). These utilities and their source are licensed under
GPL-2.0-or-later, rather than the parts library's CC BY terms. The matching
source remains in the original archive. The full GPL version 2 text is provided
as `COPYING-GPL-2.0.txt` alongside the Release assets and at
`docs/licenses/GPL-2.0.txt` in this repository; fresh installations copy it into
the cache beside the utilities.
