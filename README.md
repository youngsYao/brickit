# brick. 一颗苹果

一个可交互的积木苹果搭建网页，包含 115 颗独立积木、十步搭建、红绿黄三种配色、模型旋转与缩放、分层视图、自动搭建、零件清单下载和作品图片导出。

## 本地运行

需要 Python 3。在本目录运行：

```sh
python3 -m http.server 4173 --directory dist
```

然后访问 http://localhost:4173 。所有依赖、字体和图形资源均保存在本地，无需在线加载素材。请使用支持 WebGL 2 的现代浏览器。

## 文件

- `dist/index.html`：页面内容
- `dist/style.css`：桌面及手机样式
- `dist/app.js`：交互与搭建流程
- `dist/model.js`：积木模型、光影与图片导出
- `dist/assets/`：本地依赖、字体、图标与开源许可

本项目是独立的创意数字模型，并非官方乐高套装。模型零件清单按尺寸分类，不包含商业零件编号。
