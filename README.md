# brick.it · 把灵感搭出来

用文字描述一个想法，或上传一张照片，把它变成可以查看、编辑和逐块搭建的三维积木模型。

brick.it 将 AI 生成与积木创作工作台连接起来：从多视角参考图、零件装配，到三维预览、自由编辑和作品保存，让灵感逐步成为自己的积木作品。

[在线体验](https://brickit.dpdns.org/) · [效果展示](#效果展示) · [快速开始](#快速开始) · [AI 配置与生成流程](#ai-配置与生成流程)

## 核心功能

| 功能 | 可以做什么 |
| --- | --- |
| 文字与图片创作 | 直接描述想法，或上传图片并补充希望保留、修改的细节。 |
| 多视角参考图 | 调用生图模型，生成同一主体的正面、侧面、背面与透视图，为后续建模提供参考。 |
| AI 积木建模 | 根据参考图设计零件装配，并进行碰撞、悬空和连接检查。 |
| 三维查看与逐块搭建 | 拖动旋转、缩放、拆分查看，播放或逐步推进搭建过程。 |
| 自由编辑与零件仓库 | 搜索零件，添加、替换、旋转、改色或删除积木，支持撤销、重做和还原原始模型。 |
| 作品保存与导出 | 将草稿、版本和收藏保存在当前浏览器，导出模型图片与 CSV 零件清单；AI 生成模型还可下载原始 LDraw 文件和生成报告。 |

## 快速开始

### 在线体验

服务已部署在公网服务器，使用浏览器访问 **[https://brickit.dpdns.org](https://brickit.dpdns.org/)** 即可开始，无需在本机安装依赖。

1. **先体验示例**：在首页打开颂恩楼等内置模型，体验三维查看、逐块搭建和自由编辑。
2. **输入创作想法**：回到创作首页，填写文字描述，或上传参考图片并补充修改要求。
3. **生成模型**：确认 AI 服务已配置，点击「生成我的积木模型」，查看参考图生成、积木装配与检查进度。
4. **继续创作**：生成完成后进入工作台查看和编辑，保存版本，或导出图片与零件清单。

可以从这样的描述开始：

> 一座红瓦白墙的厦大校门，带有三个拱形入口。

也可以上传建筑照片，并补充：

> 保留图片中的建筑轮廓，把屋顶改成红色，并增加一个展示底座。

## AI 配置与生成流程

### 配置两个生成环节

打开右上角用户图标中的「AI 模型设置」，分别配置「参考图生成」和「积木建模」两个页签。每个环节都需要填写服务地址与 API Key，获取可用模型并保存。

| 环节 | 模型要求 | 作用 |
| --- | --- | --- |
| 参考图生成 | 支持图片生成与图片编辑的生图模型 | 根据文字或上传照片，生成同一主体的四视角参考图。 |
| 积木建模 | 支持图像理解与工具调用的模型 | 理解参考图，选择零件并设计装配结构，结合检查与渲染反馈修正模型。 |

界面支持兼容 OpenAI 接口的服务地址。两个环节的服务、模型和密钥独立配置，可以使用不同的服务商。

自行运行服务时，也可参考 [环境变量示例](.env.example) 配置：

| 用途 | 环境变量 |
| --- | --- |
| 建模模型 | `BRICKWRIGHT_GENERATION_MODEL` |
| 建模服务地址与密钥（OpenAI 兼容接口） | `OPENAI_API_BASE`、`OPENAI_API_KEY` |
| 生图模型 | `BRICK_IT_IMAGE_MODEL` |
| 生图服务地址与密钥 | `BRICK_IT_IMAGE_API_BASE`、`BRICK_IT_IMAGE_API_KEY` |

### 从输入到积木模型

1. **提供文字或图片**：输入创作描述，或上传参考照片，并说明想要保留或调整的细节。
2. **用生图模型生成多视角图**：将输入交给生图模型，生成同一主体的四视角参考图，包括正面、右侧面、背面和右前方俯视透视图，为后续建模补充形体信息。
3. **进行积木建模**：建模模型结合多视角参考图与文字要求，选择零件、确定位置和方向，构建积木装配。
4. **检查与修正**：执行碰撞、悬空和连接检查，并结合模型渲染与视觉反馈进行修正。视觉评审使用四视角参考图中的透视视图进行对照。
5. **进入创作工作台**：查看生成结果，播放搭建过程，自由编辑并保存作品，按需下载生成文件。

生图模型和建模模型分别产生调用费用；`BRICK_IT_MAX_COST` 控制建模环节的费用估算，不包含参考图生成费用。费用在模型响应后统计，最后一次调用可能超过设置的估算上限。

自行运行时，留空 `BRICK_IT_IMAGE_MODEL` 可使用原有的照片直接建模流程；纯文字创作需要配置参考图生成环节。

## 当前能力与限制

- **照片未覆盖的部分由 AI 推测。** 多视角参考图提供一致的建模参考，背面和遮挡区域仍属于合理推定。
- **结构检查有明确范围。** 生成模型通过的碰撞、悬空和连接检查，不包含实物承重、零件在售情况或实际装配顺序验证；逐块播放展示的是层序搭建示意。
- **编辑后的模型需要重新确认结构。** 自由编辑会改变原始生成结果，当前版本不会自动重新进行完整结构校验。LDraw 文件和生成报告对应原始生成版本；修改后需还原原始模型才能再次下载这些文件。
- **作品保存在当前浏览器。** 草稿、版本和收藏暂不跨设备同步，清除浏览器站点数据会影响已保存的作品。
- **生成依赖外部 AI 服务。** 输入内容会发送至所配置的模型服务；API Key 保存在运行后端服务的机器上。生成耗时、费用与效果受所选模型、网络和任务复杂度影响。
